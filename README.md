# MCP API Server

Un serveur MCP qui connecte Claude à des APIs en temps réel.

## Ce que j'ai appris

Ce projet m'a appris comment MCP peut rendre une IA "vivante" en lui donnant accès à des données en temps réel depuis Internet — taux de change et météo.

## Outils disponibles

- `taux_change` — Récupère le taux de change entre deux devises en temps réel
- `meteo` — Récupère la météo actuelle d'une ville
